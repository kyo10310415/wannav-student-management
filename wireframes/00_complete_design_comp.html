機能概要

アンケートスタンプラリー機能は、生徒が毎月のアンケートに回答することでスタンプを集め、 一定の条件を満たした際に特典（1時間コンサル権）のルーレット抽選に参加できるシステムです。

📊

回答率管理

継続月数に対するアンケート回答数の割合を自動計算し、視覚的に表示

🎁

特典判定

複数の条件パターンに基づいて自動判定し、達成者にDiscord通知を送信

🎰

ルーレット抽選

S評価は100%当たり、通常評価は50%の確率で特典を獲得

特典付与条件

1

2026/3以前開始：回答率80%以上

レッスン開始が2026年3月以前で、回答率≧80%

2

2026/4以降開始：6ヶ月連続回答

レッスン開始が2026年4月以降で、6ヶ月連続でアンケート回答

3

2026/3以前開始（継続6ヶ月未満）：100%達成

2026年4月から継続6ヶ月まで100%の回答率を維持

✓

共通条件

• 最新の延長審査結果が「延長」
• 生徒ステータスが「アクティブ」

特典付与後のリセット

特典を一度付与した後は条件をリセット。その後は全生徒共通で「6ヶ月連続回答」の条件2のみ適用

データベース設計

survey_responses（アンケート回答記録）

生徒ごとの月別アンケート回答を記録

カラム名 型 制約 説明
id SERIAL PRIMARY KEY 連番ID
student_id VARCHAR(50) NOT NULL, FK 生徒ID（studentsテーブル参照）
response_month VARCHAR(7) NOT NULL 回答月（YYYY-MM形式）
responded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP 回答日時
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP レコード作成日時

ユニーク制約: (student_id, response_month)
インデックス: student_id, response_month

roulette_results（ルーレット結果）

スタンプラリー達成者のルーレット抽選結果を記録

カラム名 型 制約 説明
id SERIAL PRIMARY KEY 連番ID
student_id VARCHAR(50) NOT NULL, FK 生徒ID
result VARCHAR(20) NOT NULL 抽選結果（'当たり' or 'はずれ'）
probability INTEGER NOT NULL 当選確率（100=必ず当たり、50=50%）
roulette_url TEXT NOT NULL ルーレットページのURL
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP 抽選日時

インデックス: student_id, created_at

stamp_rally_achievements（スタンプラリー達成記録）

特典達成条件を満たした生徒を記録

カラム名 型 制約 説明
id SERIAL PRIMARY KEY 連番ID
student_id VARCHAR(50) NOT NULL, FK 生徒ID
achievement_type VARCHAR(50) NOT NULL 達成条件タイプ（initial_80/continuous_6/catch_up_100/reset_6）
achievement_date DATE NOT NULL 達成日
notified_at TIMESTAMP NULL Discord通知送信日時（NULL=未送信）
roulette_url TEXT NULL 送信したルーレットURL
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP レコード作成日時

インデックス: student_id, achievement_date

学生管理画面UI

既存の学生管理テーブルに以下のカラムを追加します:

追加カラム

  • アンケート回答数: 生徒が回答したアンケートの累計回数
  • 回答率: 回答数 ÷ 継続月数 × 100%（プログレスバー表示）
  • ルーレット結果: 最新の抽選結果（当たり/はずれ/未達成）
実装時は wireframes/01_student_management_survey.html を参照してください

レッスン予約・Today画面UI

特典対象の生徒をルーレットアイコン（🎰）で表示し、一目で判別できるようにします。

🎰

S評価生徒（金色）

必ず当たり（100%）の特典対象生徒に表示。金色のグラデーション背景で目立たせます。

🎰

通常評価生徒（緑色）

50%当たりの特典対象生徒に表示。緑色のグラデーション背景で表示します。

実装時は wireframes/02_lesson_today_markers.html を参照してください

Discord通知メッセージ

通知タイミング

ルーレット抽選画面

抽選ロジック

  • S評価: 必ず「当たり」（probability=100）
  • 通常評価: 50%の確率で「当たり」（probability=50）
  • 記録: 結果はroulette_resultsテーブルに保存

セキュリティ

  • 1回限り: URLは使用後無効化
  • 有効期限: 発行から30日間
  • 認証: 生徒本人のみアクセス可能

実装ガイド

1

データベースマイグレーション実行

migrations/20260319_add_survey_stamp_rally.sql を実行

または node src/db/migrate.js で自動マイグレーション

2

APIエンドポイント作成

必要なエンドポイント:

  • GET /api/survey/responses/:studentId - 回答記録取得
  • POST /api/survey/responses - 回答記録登録
  • GET /api/survey/eligible-students - 特典対象生徒一覧
  • POST /api/roulette/generate - ルーレットURL生成
  • POST /api/roulette/spin - ルーレット抽選実行
  • GET /api/roulette/result/:token - 抽選結果取得
3

フロントエンド実装

学生管理画面:

  • 回答数・回答率カラムを追加
  • ルーレット結果カラムを追加
  • 特典対象バッジの表示

レッスン予約・Today画面:

  • ルーレットアイコン（🎰）の表示
  • S評価と通常評価の色分け
4

Discord通知実装

  • 特典達成判定のバッチ処理を作成（日次実行推奨）
  • Discord Webhook APIを使用して通知送信
  • 通知テンプレートを実装（HTML Embedに対応）
  • ルーレットURLを生成して通知に含める
5

ルーレットページ実装

  • URLトークン検証機能の実装
  • ルーレット抽選ロジックの実装（S評価100%、通常50%）
  • 回転アニメーション（2秒間、720度回転）
  • 結果画面の表示（当たり/はずれ）
  • 結果のDB保存
6

テスト・デプロイ

  • テストデータでの動作確認

  • Discord通知のテスト送信
  • ルーレット抽選のテスト（S評価/通常評価）
  • 本番環境へのデプロイ
